VERSIÓN ACTUAL: v0.3.0
-----------------------
El sistema está operativo en modo desarrollo local con túnel ngrok.
Recibe mensajes de Instagram vía Meta Webhook, los analiza y muestra
los resultados en un dashboard web con login multiusuario.


LO QUE ESTÁ CONSTRUIDO
-----------------------
[v0.1] Integración con Meta Webhook + persistencia en Supabase.
[v0.2] Migración a SQLite local. Pipeline de análisis completo:
       URL Analyzer + Text Analyzer + IA UM Cloud (gemma4-26b).
       Prompt ajustado a norma académica. Fix de id_conversacion
       bidireccional (sha256 del par sender/recipient).
[v0.3] Dashboard web con login multiusuario (bcrypt + cookies firmadas).
       Auth modular (auth.py). Módulo de notificaciones (messenger.py).
       Scripts de setup de usuarios y migración de IDs.
       Documentación técnica completa en src/docs/.


ARQUITECTURA ACTUAL (resumida)
-------------------------------
  Meta Instagram  →  POST /webhook
                          │
                    BackgroundTask
                          │
               PhishingOrchestrator.analyze()
                 ├── URLAnalyzer  (sync, heurístico)
                 ├── TextAnalyzer (sync, heurístico)
                 ├── URLhaus API  (async, confirmación online)
                 └── UM Cloud AI  (gemma4-26b, clasificación MITRE)
                          │
                     SQLite (aiosqlite)
                          │
                   Dashboard /dashboard  (HTML inline, auth bcrypt)
